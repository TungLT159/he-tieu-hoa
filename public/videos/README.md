# Learning Video Assets

Place the real learning video files in this folder when they are available:

- `bắc.mp4` for the Northern voice video source used by the viewer video panel.
- `trung.mp4` for the Central voice video source used by the viewer video panel.
- `nam.mp4` for the Southern voice video source used by the viewer video panel.
- `he-tieu-hoa.vtt` for captions or subtitles.

Do not commit placeholder binary media. The viewer shows a fallback message when the video file is missing.
